# Calculadora de Finiquito PFVR

Calculadora de finiquito y liquidación laboral conforme a la Ley Federal del Trabajo, de PFVR Soluciones Legales (Lic. Pedro Fernando Villarreal Rodríguez).

Los cálculos se ejecutan en el navegador de quien la usa: no se guarda ni se envía ningún dato. El resultado es una estimación informativa y no sustituye la asesoría jurídica.
